# Skibidi Archive

A personal, orange-and-black character archive.

## Current page
Cameraman 1056

## Files
- index.html: character page
- style.css: visual design
- script.js: search bar

## Adding another character
Duplicate index.html, change the content, then add the character to the `chars` array in script.js.

## Note
The Cameraman 1056 page is a paraphrased personal-style presentation based on the information visible in the Skibidi Toilet Wiki/Fandom page. It is not affiliated with Fandom or the creators of Skibidi Toilet.
